# Askalot Platform Release — 2026-10-07

This release changes how you lay out the columns of a Gold file in Analysis:
you arrange the columns themselves instead of writing a list of operations.

## Highlights

- **Arrange a Gold file's columns directly.** The Gold page of a Bundle now shows the file's columns as they will be exported. Drag a column by its grip to move it, double-click its name to rename it, and drag it back onto the Silver columns list to leave it out of the file. Nothing is deleted: a column you left out stays in the Silver list and can be served again at any time. In a wide dataset, type in the search box to find a column, or click a column's position number and type where it should go. Everything works from the keyboard too; the keys are listed at the bottom of the page.

- **Computed columns are built from the columns you pick.** Drag columns onto **New computed column**, or pick them from its list, and add a computed column from them: arithmetic, a recode into ranges, or a concatenation. A computed column can read a column you renamed or left out of the file.

- **Nothing changes until you save.** Undo steps back through your edits, Discard returns to the saved layout, and Reset returns to the full Silver column set. **Save** stores the layout and **Derive** builds the Gold file from it. The operations behind the layout are still listed on the page, read-only.

## Fixes & improvements

- **A first edit no longer drops the other columns.** Renaming or removing one column used to produce a Gold file with only the columns the recipe named, and without their labels. Every column stays unless you remove it, and labels and value labels carry over.
- **Two columns cannot end up with the same name.** A rename or computed column that would duplicate another column's name is refused with a message naming both.
- **A build tells you what it skipped.** If the Silver dataset no longer has a column the layout removes or positions, the Gold file is still built and the result lists what was skipped.
- **A layout saved from an out-of-date page is refused.** If the Silver dataset or the saved layout changed after you opened the page, Save asks you to reload instead of overwriting the newer state, and a build that started before a save says so.
- **Members who cannot edit a Bundle see its layout read-only.**
- **Collapsible sections announce their state.** The sections you open and close in Analysis and on a survey's detail page now tell a screen reader whether they are open, and the Assign Interviewers section of a campaign shows the number of selected interviewers in its header.
- **More of each row opens it.** On a Bundle's Export page a stage now opens from its whole header, with the export buttons always in view. On a questionnaire's Design quality scorecard each dimension with evidence opens as a row, and its information button no longer opens the row. On the Silver page a coding dimension opens from its labels as well as its arrow.
- **AI assistants and the API:** `create_gold_dataset` takes the same `operations` list the page saves; the separate raw `fields` argument is gone.

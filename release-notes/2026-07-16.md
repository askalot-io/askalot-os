# Askalot Platform Release — 2026-07-16

> First public release note. Askalot platform releases are identified by their release date; this note describes the version currently in production and the changes that shipped with it.

## Highlights

- **Smarter document retrieval.** Document search and AI retrieval now use a cross-encoder reranking stage, noticeably improving the relevance of passages the AI agents ground their answers in.
- **Better-grounded questionnaire design.** During ideation, the AI Designer now sees a topic index of your uploaded reference documents, so early Research Brief drafts draw on the full corpus instead of a single retrieval pass.
- **Bundle quality workflow.** Deriving Silver datasets is now fully asynchronous and conflict-safe, and AI-assisted open-end coding progress is visible while it runs.

## Fixes & improvements

- **Reliability batch** across billing, respondent management, authorization checks, bundle quality, and document ingestion — two rounds of fixes that remove silent-failure paths and surface errors loudly instead.
- **Mass-fill simulations** now report a failed state when every generated survey fails, instead of appearing stuck.
- **API surface cleanup.** Legacy dataset-scoped REST routes were retired in favor of the current bundle-centric API; the OpenAPI description now documents authentication schemes explicitly.
- **Survey completion status** is now determined by a single source of truth, eliminating rare inconsistencies between interviewer and respondent views.

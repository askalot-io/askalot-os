# Askalot Platform Release — 2026-10-08

This release finishes the Gold column layout in Analysis: one column can be
served under several names, and a computed column can stand anywhere in the file.

## Highlights

- **Serve one column under several names.** On the Gold page of a Bundle, drag a column that is already in the file from the Silver columns list a second time, or press **A** on its chip. It becomes a second column of the file with the same values, where you dropped it, under a free name you can change by double-clicking. The Silver list shows how many times each column is served.

- **Put a computed column anywhere.** A computed column now stands among the file's other columns as a chip of its own. Drag it by its grip, or move it from the keyboard, and the Gold file is written in that order. A new computed column still starts at the end.

- **A questionnaire's flow diagram says what is wrong with an item.** Every item with an error finding now shows the finding as a line of text on its node, one line per finding, with the whole message and its suggestion on hover. Before, some errors had no colour of their own and the item looked healthy.

## Fixes & improvements

- **Leaving out a column keeps its other names.** If a column is served under more than one name and you remove the first, the next one takes its place.
- **Names stay distinct.** An extra name that would repeat another column of the file, or the name of a Silver column, is refused with a message naming both.
- **AI assistants and the API:** the `operations` list of `create_gold_dataset` takes an `alias` operation, and `reorder` can name an alias or a computed column.

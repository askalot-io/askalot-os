# Askalot Platform Release — 2026-10-13

This release brings a new questionnaire editor that runs in your browser, as a
preview beside the existing one, and makes it safe for you and the Designer to
work on the same questionnaire at the same time.

## Highlights

- **A new editor, as a preview.** Under each project in the editor's project list, **Open in the new editor (preview)** opens the project in an editor that runs in your browser and starts no session. It has the same panels: the questionnaire with the flow diagram beside it, the Designer chat, the project's documents and the Research Paper. Both editors save to the same version history, so you can move between them freely. The existing editor stays the default.

- **Your edits and the Designer's no longer overwrite each other.** When you save while the Designer is working, its save keeps your lines: changes in different places are merged, and where both touched the same lines the Designer reads your version and applies its change again. In the new editor, a change made elsewhere reaches your open tab within seconds, and you are asked only when it touches the lines you are editing.

- **A guide to the research flow on your home page.** For the selected project, the home page shows the stages of a study, which ones are done, and a link to the next step.

- **The flow diagram shows what a Roster repeats over.** A Roster block now carries its iteration expression as a label of its own, with an arrow from each answer or variable it reads.

## Fixes & improvements

- **The Designer's approval request shows the real change.** The diff used to show the whole questionnaire as new; it now shows only what the Designer changed.
- **"Auto-accept edits" does what its label says.** Ticked before you send a message, it applies to that turn. "This turn" switches itself off when the turn ends, however it ends.
- **Undo of a Designer turn never removes your own save.** If you saved while the turn was still running, the undo is refused, as it already was for a save made afterwards.
- **The audit viewer opens faster.** The first page of a long event list now appears in under a second.
- **Signing in with Google or Microsoft from an AI assistant works**, and an assistant connected to your workspace no longer asks which workspace to sign in to.
- **Filling a campaign with synthetic respondents is more reliable**: long answers are no longer cut off, and a run that cannot continue says why instead of waiting.
- **The AWS Bedrock connection test** on your profile checks the stored keys whichever provider you selected for reasoning.

## AI assistants and the API

- **Saving a questionnaire now names the version it was written from.** `save_qml_file` and `finalize_upload` take a required `base_version_id`. `get_qml_content` and `create_questionnaire` return the current `version_id`; pass it back when you save. If someone else saved in the meantime, the answer says `merged` and returns the stored content, or `overlap` when the same lines changed, in which case read again and re-apply.
- **If you use the Askalot plugin for Claude Code, update it** to get instructions that follow this. An older plugin's saves are refused with a message naming the missing argument; nothing is overwritten.

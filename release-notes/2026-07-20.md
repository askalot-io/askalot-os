# Askalot Platform Release — 2026-07-20

## Highlights

- **Redesigned analysis workspace, built around Bundles.** The statistical-analysis workspace is now organized entirely around *Bundles* — each Bundle binds a project, its questionnaire, and a chosen set of campaigns to a single Bronze → Silver → Gold dataset chain. Every Bundle now has its own dedicated phase pages (Bronze extraction, Silver coding & weighting, Gold refinement, and Export), so each step of preparing a dataset has a clear home instead of a flat list of loose datasets.
- **Editable Calibration Targets for weighting.** You can now define and adjust the exact demographic targets your data is weighted toward, per Bundle. Targets are seeded from your sampling strategy the first time you open the Silver stage, then edited freely — reassigning the strategy afterward no longer overwrites the targets you've tuned.
- **A clearer, three-part data-quality story.** Dataset quality is now presented as three distinct measures: how your fielded sample compares to your sampling strategy, how your weighted data compares to your calibration targets, and the quality of the responses themselves. Each measure states plainly when it can't be computed yet (for example, no strategy assigned) rather than folding gaps into a single opaque score.

## Fixes & improvements

- **Consistent quality across the app, API, and AI.** The analysis screens, the public API, and the AI Analyst now all read the same quality document, so the numbers you see in the interface match what the API returns and what the AI reasons over.
- **Clearer API guidance for survey answers.** API and integration documentation now explains the survey answer-code contract explicitly, and requesting a survey's presentation format is documented end-to-end.
- **Sturdier editing under concurrency.** Editing a Bundle's campaign set, calibration targets, or refinement recipe now safely invalidates the affected downstream stages, so a stale dataset can't be mistaken for a current one.

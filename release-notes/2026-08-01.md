# Askalot Platform Release — 2026-08-01

## Highlights

- **Per-answer response timing on survey detail pages.** A survey now opens into a per-item accordion showing each question, the answer given, and how long the respondent spent on it — so a rushed section or an abandoned stretch is visible directly instead of inferred from a single completion time. The data-degradation warnings on the same page were repaired and now describe what was actually measured, rather than reporting a score for something that could not be computed.

- **Faster, better-grounded document processing.** Uploaded PDFs are now parsed on GPU, and documents are split along their own semantic structure instead of at fixed character counts — improving both processing time and the coherence of the passages AI agents cite back to you. Questionnaires, Research Briefs and document summaries also moved to a single canonical store, so the editor, the REST API and the AI assistant always read exactly the same text.

- **Deleting a document now means it stays deleted.** Removing a document from a knowledge base is permanent: previously a background reconciliation could re-index a document minutes after it was purged, so it reappeared on its own. Records deleted elsewhere in the platform are now durably scrubbed on a schedule as well, rather than only being marked as deleted and retained indefinitely.

- **A noticeably quicker platform.** A round of efficiency work removed duplicated effort on the paths you use most. Publishing a questionnaire no longer runs its formal-verification pass twice; the analysis board and the audit feed now resolve every name they display in one batched read instead of one lookup per row. None of this ever surfaced as an error — only as waiting.

## Fixes & improvements

- **Authorization hardening.** A dedicated review pass tightened permission checks across campaign, survey, respondent-pool and analysis operations, so each action is authorized against the specific record it touches rather than only the container it sits in. Project and document listings are now consistently scoped to your active organization.
- **Honest survey routing.** Questionnaire logic no longer continues past a condition it cannot evaluate. The run reports the problem instead of quietly choosing a branch.
- **A clearer audit trail.** Audit entries now distinguish actions taken by Askalot operators from actions taken by members of your own organization.
- **First-login password change.** Newly provisioned administrator accounts must set their own password before they can use the platform.
- **One current Gold dataset per chain.** Building a new Gold dataset now reliably retires its predecessor, so a chain can no longer end up with two datasets each presenting itself as the current one.
- **Consistent confirmations, self-hosted front end.** Destructive actions across the platform now share one confirmation dialog that behaves the same way everywhere — including when scripting is unavailable, where it previously proceeded without asking. The interface's front-end libraries are now served by Askalot itself instead of third-party CDNs, with pinned, verified versions.
- **Honest status while models wake.** When local inference has been idle-parked to save power, the platform now reports that models are waking rather than appearing unhealthy or simply hanging.
- **Interface consistency and a visual refresh** across listing and detail pages, plus a repaired landing page and refreshed iconography.

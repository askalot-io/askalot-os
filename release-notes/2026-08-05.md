# Askalot Platform Release — 2026-08-05

## Highlights

- **Every capability is now open to every plan.** Askalot no longer gates functionality behind a tier. The full analysis pipeline — coding open-ended answers, weighting, building refined datasets, and the AI Analyst that reads them — is available to all accounts, as is the Research Brief. Exports are open too: CSV, Excel, SPSS and Parquet are no longer restricted, and **R (`.rds`) export is new**, arriving with your categorical variables already converted to R factors and your value labels preserved as factor levels. Plans still differ, but on release cadence, uptime commitment and support — not on what you can build.

- **The limits on how much you can build are gone.** Projects were previously capped at 50 campaigns and 100 respondents, and a campaign could not be fielded on a questionnaire longer than 30 items. All three caps have been removed outright rather than raised. A long instrument, a large panel, or a project with many parallel campaigns is now simply supported.

- **Roster data reaches your datasets.** Question groups and matrix questions nested inside a roster were being dropped during dataset extraction — the answers were collected and stored, but never appeared in the extracted data. They now come through, with one consistent column-naming rule across the pipeline so the same question produces the same column name everywhere. If you have fielded a roster containing grouped or matrix questions, re-extract to pick up the previously missing columns.

- **Dataset extraction no longer fails on simple questionnaires.** A questionnaire that took no data from an external source could fail to produce a dataset at all. Extraction now completes for those questionnaires.

## Fixes & improvements

- **Privacy and authorization hardening.** A further review pass tightened how personal data is retained and how privileged actions are authorized. Retention behaviour for respondent records is now documented precisely, including which demographic fields are deliberately kept so that weighting stays possible after identifying details are erased.
- **A more trustworthy audit trail.** Audit events are now recorded and routed through a single definition shared by the components that write and read them, closing a path where events could be recorded against the wrong destination or lost. Every event carries the organization it happened in and whether it was performed by an Askalot operator or by a member of your own organization.
- **Faster AI retrieval under load.** Concurrent requests to the AI assistant's document-retrieval tools no longer wait behind one another, so a slow search stops delaying every other request in the same session.
- **Clearer waiting times when models are idle.** When local models have been parked to save power, the estimated wake time reported to you is now measured from a real wake rather than inherited from a slower recovery path, so the wait you are shown matches the wait you get.
- **AI request compatibility.** Updated to a newer form of the AI provider's request format, replacing a parameter that had been deprecated.

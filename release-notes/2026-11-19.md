# Askalot Platform Release — 2026-11-19

Each wave of a study now sizes the next one from what it actually achieved.

## Highlights

- **Waves learn from each other.** When a wave's results are written to the Research Paper, the Study now records, for every KPI you sized, how many usable responses it got, the precision it actually reached and the response yield. The Size Planner proposes the next wave's sample from those numbers instead of from defaults, and marks each one as coming from the paper so you can check it.
- **Check a questionnaire before you create it.** Through the Askalot plugin and the API, a new questionnaire can now be validated as text before it is saved, so problems are fixed before the first version exists. The plugin's skills have been checked against the platform and corrected where they described it inaccurately.

## Fixes & improvements

- Undoing a Designer turn now also undoes the translations that turn wrote, for questionnaires and the Research Paper.
- The questionnaire diagram in the editor now draws when the editor is opened in a browser on Windows.
- In surveys written in a right-to-left language, interface text such as a dropdown's "Select…" now keeps the interface language and direction. The dot of a selected radio button now sits in the centre of its circle.
- List pages in campaign management fit their columns to the labels of the language you use. The Surveys list shows an arrival badge only when a survey did not arrive the usual way.

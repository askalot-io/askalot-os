# Askalot Platform Release — 2026-10-19

This release keeps the AI panels on the newest Claude models, makes campaigns
follow their fielding, and fixes a set of rough edges across Bundles, the logic
check and document search.

## Highlights

- **The newest Claude models, automatically.** Each AI panel now uses the latest Claude model available to your connection, so new model releases reach the Designer, Manager and Analyst without a settings change.

- **Campaign status follows fielding.** A campaign's status now reflects whether it is actually fielding, and a paused campaign accepts no new answers until you resume it.

- **Clearer sign-in for connected apps.** When an AI app asks to connect to your Askalot account, the sign-in page names the app that is asking and where access goes.

- **Announcements from the Askalot team** appear under the navigation bar, for example ahead of a planned maintenance window.

## Fixes & improvements

- **The logic check badge always reflects your questionnaire's latest version**, including after an undo or a clone.
- **A range question's answer is always a low and a high value.** Answers stored in any other form could not be reopened; they now show as unanswered.
- **Cloning a Bundle while its data is being rebuilt** asks you to try again instead of copying a half-built dataset.
- **Document search in small projects** returns every matching passage.
- **Documents of a deleted project** stop appearing in search right away.
- **Indexing a long document through an AWS (Bedrock) connection** no longer fails when the sign-in renews part-way through. An AWS sign-in that has ended now says so, and the connection test names each outcome.
- **Saving a Gold column layout** reaches the dataset you are working on, and the layout locks while it saves.
- **Project cards count surveys**, list pages fit their screen, and a malformed link shows as not found.
- **Deleting a project also deletes its Bundles**, the sign-in discovery link works, datasets are preselected where you would expect, and audit dates display correctly.
- **The questionnaire editor** no longer shows an error page when a server process restarts, and its links and requests behave as labelled.
- **AI tool calls stay responsive** while a large questionnaire is being validated.

## Good to know

- The QML engine's public source release now ships an installable package alongside each version.

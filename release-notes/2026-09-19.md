# Askalot Platform Release — 2026-09-19

The previous release made a preview something that cannot become research data.
This one is largely about trusting what the platform tells you: a quality grade
that says which version of your instrument it graded, a weighting measure that
grades against the design it was drawn from rather than whatever is nearest, and
an AI model setting that says where it came from. Alongside those, testing your
own questionnaire is now something you can reach from the page where you work.

## Highlights

- **Test a questionnaire, from the page you already work on.** A third tab on the survey-execution landing page lists every questionnaire you can reach, each with a one-click preview. You no longer have to go to the campaign side to try out an instrument. A questionnaire that a live campaign is fielding is marked, with a note that the preview walks your current draft rather than the version that campaign pinned — because those can differ, and you should know which one you are looking at. The tab appears only when you can reach at least one questionnaire, and opens by default when you have no assigned work and no running campaigns, which is exactly the case where the old page had nothing to offer you.

- **A quality report says which version of your questionnaire it graded.** A stored report used to be shown whenever it existed, so an instrument edited after it was assessed carried a grade describing text it no longer held — and the "assessed on" date was the only hint. A report is now shown only while it still matches the current draft. If you have edited since, the panel tells you it has not been assessed rather than showing you a number that is quietly about something else.

- **Every weighting measure grades against the design the sample came from.** The measures that report how well a fielded sample matches its target now resolve each factor through the design that drew it, one rule in one place, so the leg that grades cannot disagree with the leg that selected. Two surfaces reporting different answers for the same factor was possible before; it is not now. A factor's target keys are also checked when you set them, at every door that can do the checking, instead of failing later during analysis.

- **Calibration targets show the design's own factors.** A study's factors are listed where you set its targets, each with a checkbox saying whether it is raked on, so what the analysis will weight on is visible next to the numbers you are entering rather than held in your head.

- **Straightlining detection, and JSON export.** Responses that run straight down a shared answer scale are now reported as a data-quality signal. Datasets export as JSON alongside the existing formats, and every export route now goes through one list of formats and one set of checks — so a format offered on one screen behaves the same on all of them.

- **AI model settings say where they come from.** Each model slot now shows whether its value is yours, your organisation's, or the platform default, so a setting you did not choose is distinguishable from one you did. An assistant working on your behalf can read and change your own slots, with the change recorded like any other.

- **A document whose summary failed says so.** An uploaded reference document with no summary meant two different things — one still being processed, one whose last attempt failed — and both were reported as the self-healing case. The difference is now recorded and visible, so an assistant reading your material can tell you it is missing rather than implying it is coming.

- **No page loads assets from a third-party network.** Icon fonts are served from Askalot's own domain rather than a public CDN, so opening any page makes no request to a third party.

## Fixes & improvements

- **Campaign invitations respect the study's admission rule at every door.** Sending invitations to people the campaign does not admit is refused where it is requested, not discovered afterwards.
- **A proposal round that found nothing is reported as a round that ran**, with the retry still offered, rather than appearing to have failed.
- **Transient AI-provider faults are retried** rather than failing the whole document, and a model that rejects a setting is remembered so the next call does not repeat it.
- **Failures inside the knowledge-base indexer are surfaced and retried once.** Some previously completed silently, leaving a document that looked indexed and was not; a query that fails is now reported as a failure rather than as an empty result.
- **Indexing progress survives a restart**, and deleting several documents at once no longer has them contend with each other.
- **A missing knowledge base is reported as missing** instead of as an empty one.
- **Rows left behind by sealing an organisation are healed automatically**, and a panel watching for reconciliation now hears it.
- **The survey-execution landing page asks the database for your own rows**, rather than reading the organisation's and narrowing afterwards — noticeably faster in a large organisation.
- **A paid plan is labelled from what was actually granted under it**, so the tier shown matches the entitlements in force.
- **Back-navigation through a questionnaire was measured and repaired.**
- **An expired sign-in no longer signs you out of the editor mid-session**, and the editor's AI panel works on all model slots.
- **A dataset's stage-failure reason no longer quotes response content** to callers who should not see it.
- **Audit records name the entity that was acted on**, so a history is readable without cross-referencing.
- **Assistant-facing responses are bounded**, so a long result is truncated predictably rather than being rejected by the client.
- **Session security around token renewal has been hardened.** No action is needed on your part.

# Askalot Platform Release — 2026-11-21

Claude now connects to Askalot through one address, whichever environment holds your account.

## Highlights

- **One address for Claude.** Connect Claude Code, Claude Desktop or claude.ai to `https://askalot.io/mcp`. You sign in with your usual Askalot account, and Askalot finds the environment and organization your work is in. You no longer need to know which server address to use.

## Action needed

- **Sign in again once.** Connections made before this release stop working. Update the Askalot plugin (or point your connector at `https://askalot.io/mcp`) and sign in when Claude asks.

## Fixes & improvements

- In the questionnaire editor, the bottom panel now opens only when the analyser reports errors or warnings, and no longer takes the keyboard when it does.
- The QML syntax, preconditions and data-quality documentation has been clarified.
- Tools in the Askalot connector now show readable names in your AI client's tool list, and tools that only add data are no longer marked as destructive.
